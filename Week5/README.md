## 🚀 Mini-Project: Linear Algebra Explorer
An interactive Python script that:
- Demonstrates vector and matrix operations step by step
- Computes dot products and shows geometric meaning
- Finds eigenvalues/eigenvectors and visualizes them
- Saves visualizations as PNG files

## 🔧 Setup & Run
```bash
cd mini-project
pip install -r requirements.txt
python linalg_explorer.py
```
