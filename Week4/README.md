## 🚀 Mini-Project: Student Data Analysis
Analyzes a CSV student dataset using:
- Pandas for data loading, cleaning, merging, groupby
- Matplotlib for bar charts and histograms
- Seaborn for heatmaps and distribution plots

## 🔧 Setup & Run
```bash
cd mini-project
pip install -r requirements.txt
python analyze.py
```
Charts will be saved as PNG files in the `mini-project/` folder.
